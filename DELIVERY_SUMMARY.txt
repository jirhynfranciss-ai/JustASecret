TABLES CREATED:
1. questions
   - id (UUID, primary key)
   - question_text (TEXT)
   - question_type (VARCHAR: TEXT, LONG_TEXT, YES_NO, SINGLE_CHOICE, MULTIPLE_CHOICE)
   - options (JSONB array of choices)
   - is_required (BOOLEAN)
   - is_active (BOOLEAN)
   - display_order (INTEGER)
   - conditional_question_id (UUID, for conditional logic)
   - conditional_value (TEXT)
   - created_at (TIMESTAMP)
   - updated_at (TIMESTAMP)

2. responses
   - id (UUID, primary key)
   - session_id (UUID, unique)
   - submitted_at (TIMESTAMP)
   - created_at (TIMESTAMP)

3. answers
   - id (UUID, primary key)
   - response_id (UUID, foreign key)
   - question_id (UUID, foreign key)
   - answer_text (TEXT)
   - created_at (TIMESTAMP)

4. admin_settings
   - id (UUID, primary key)
   - setting_key (VARCHAR, unique)
   - setting_value (TEXT)
   - updated_at (TIMESTAMP)
