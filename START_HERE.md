# 🌹 START HERE

Welcome to your beautiful "Can I Get to Know You?" questionnaire application!

## ⏱️ 3-5 Minute Quick Start

Follow these steps to get running locally:

### Step 1: Create Supabase Project (5 min)
```bash
# 1. Go to https://supabase.com
# 2. Click "New Project"
# 3. Fill in project name
# 4. Wait 2-3 minutes for initialization
```

### Step 2: Setup Database (2 min)
```bash
# In Supabase Dashboard:
# 1. Click "SQL Editor" in sidebar
# 2. Click "New Query"
# 3. Open the file: supabase/schema.sql
# 4. Copy ALL contents
# 5. Paste into Supabase SQL Editor
# 6. Click "Run" button
# Done! Database ready with all tables and default questions
```

### Step 3: Configure (1 min)
```bash
# 1. Edit .env file in this project
# 2. In Supabase, go to Settings → API
# 3. Copy "Project URL" → VITE_SUPABASE_URL in .env
# 4. Copy "Public/Anon Key" → VITE_SUPABASE_ANON_KEY in .env
# 5. Save .env
```

### Step 4: Run (1 min)
```bash
npm install
npm run dev

# Open http://localhost:5173 in your browser
# 🎉 You're live!
```

### Step 5: Create Admin Account (2 min)
```bash
# In Supabase:
# 1. Go to Authentication → Users
# 2. Click "Create new user"
# 3. Email: admin@example.com (your email)
# 4. Password: Your password
# 5. Click "Create user"
# Done! Can now log in to admin
```

## ❓ Common Questions

**Q: Do I need to sign up for anything?**
A: Yes, Supabase (free). Vercel is free too.

**Q: Do users need to log in?**
A: No! Public can fill out without any account.

**Q: Is my data safe?**
A: Yes! Row Level Security (RLS) prevents data leaks.

**Q: Can I customize it?**
A: Yes! See CUSTOMIZATION.md for details.

**Q: How much does it cost?**
A: Free! Both Supabase and Vercel have generous free tiers.

**Q: How do I go live?**
A: Deploy to Vercel (see DEPLOYMENT.md). Takes 5 minutes.

**Q: Can I add more questions?**
A: Yes! Use Supabase SQL or admin panel.

**Q: What happens to responses?**
A: They're stored in Supabase database. You can view in admin.

**Q: Can I delete responses?**
A: Yes! Use Admin → Responses → Delete button.

**Q: Can I export data?**
A: Yes! Use Admin → Responses → Export CSV button.
